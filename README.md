Vice City Cover Studio — an offline web app that turns any photo and a caption into GTA 6-style multi-panel cover art: four poster layouts, Vice City sunset and neon colour grades, bold condensed lettering with a neon script subtitle, and one-click PNG export in 1080 × 1080, 1080 × 1350 and 1920 × 1080. Photos never leave the machine; everything runs from static files with no network request.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — add your photos, pick a layout and grade, edit the caption, drag each photo into place, and export the PNG.
